# Changelog

Toutes les modifications notables apportées à **LabCraft** sont documentées dans ce fichier.
Ce projet suit le format [Keep a Changelog](https://keepachangelog.com/fr/1.1.0/).

Pour chaque entrée ci-dessous, l'impact est systématiquement distingué en deux catégories :
- **(a) Équilibre, couverture ou verdict** : modifie les énergies libres `ΔG` injectées dans le solveur multi-espèces, les concentrations à l'équilibre, le statut de couverture `labcraft coverage` ou la classification globale du panel (`OK` / `INFO` / `WARNING` / `FAILURE`).
- **(b) Affichage, `Tm`/`ΔH`/`ΔS`, JSON, CLI ou outillage seulement** : enrichit les métadonnées rapportées, la documentation, le typage ou l'empaquetage sans modifier ni l'équilibre thermodynamique ni le verdict.
